# 技術拆解：如何把互動解剖展示方法轉成蝴蝶標本

## 1. 資產先行

主體不是由幾個簡單平面拼湊。四片翅膀各自使用 70 × 90 分段的高密度曲面，並透過 Catmull-Rom 輪廓、曲率、波紋與法線重建形成可被光線雕刻的立體表面。翅面再結合四張獨立 WebP 資產紋理，保留翅脈、翅鱗與邊緣細節。

## 2. 角度依賴結構色

翅面 Fragment Shader 同時讀取：

- 視線與表面法線夾角
- 程序化翅鱗微表面
- 翅面資產紋理
- 前後表面方向
- 冷暖主光、補光與輪廓光

接近掠射角時，色彩會由深藍逐漸偏向青藍與紫藍，並提高方向性高光。這不是精確的奈米光學模擬，但比固定藍色材質更接近結構色的視覺行為。

## 3. 標本攝影構圖

鏡頭使用 34° 垂直視角，降低廣角變形。模型置於暖色展台上，背景使用暖白漸層與低對比介面，讓藍色翅面成為唯一高飽和主角。

## 4. 陰影與效能

場景沒有建立高解析度即時 Shadow Map。展台上的接觸陰影由一張徑向衰減平面在 Shader 中生成，成本低且不會在軟體渲染或行動裝置上造成多一次完整幾何 Pass。

## 5. 分層檢視

- Layer 0：完整資產翅面
- Layer 1：降低翅面不透明度並顯示獨立翅脈網路
- Layer 2：進一步透明化翅面，強調膜層與支撐關係

腹面比較不是換一張靜態圖片，而是將整個 3D 標本翻轉，Wing Shader 根據正反面選擇不同材質。

## 6. 表面熱點

每個熱點保存標本局部座標。每幀將局部座標依照翼根動畫、全局旋轉、相機 View-Projection 矩陣投影到螢幕；WebGL 點精靈負責深度感，DOM 按鈕則提供點擊範圍、文字標籤與鍵盤可及性。

## 7. 行動裝置

窄螢幕時，介面由三欄改成垂直流程，工具列移至底部。相機距離依實際 Stage 寬度增加，避免蝴蝶在直向畫面被裁掉。Pixel Ratio 也會依螢幕與硬體執行緒數量限制。
