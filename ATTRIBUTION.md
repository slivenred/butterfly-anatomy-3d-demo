# Concept Source and Attribution

## Primary concept source

This project was conceptually inspired by:

- Repository: [`thebuggeddev/anatomy`](https://github.com/thebuggeddev/anatomy)
- Concept creator: GitHub user [`@thebuggeddev`](https://github.com/thebuggeddev)
- Public reference demo: `anatomy-livid.vercel.app`

The parts studied and reinterpreted were the **presentation method and interaction model**, including:

- a central specimen-first three-column workspace
- a warm, low-contrast museum and editorial visual language
- narrow-field specimen-style camera framing
- studio-like warm/cool lighting and contact grounding
- a vertical viewer tool rail
- isolate, section, layer and comparison exploration modes
- hotspots that visually belong to and follow a 3D specimen
- performance decisions that favor rendering only while visible or changing

## What this repository does not copy

This repository does **not** contain or redistribute the reference project's:

- source code
- 3D organ models
- textures or illustrations
- organ copy or structured anatomy data
- other bundled assets

The butterfly geometry, WebGL 2 renderer, shaders, wing assets, flight animation, hotspots, user interface, documentation, screenshots and feature-tour video were independently created for this project.
